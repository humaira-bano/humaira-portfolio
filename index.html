🚀 Featured Project

A real project built to solve a student problem

📚 StudyFlow

Personal Student Productivity System

📖 Project Overview

StudyFlow is a personal study productivity system designed to help students organize their study tasks, focus sessions, daily goals and progress in one place.

❗ The Problem

Students often manage their study tasks, goals and study time using different tools, making it difficult to see their overall progress.

💡 The Solution

StudyFlow brings task planning, focus sessions, goals and analytics together in one simple dashboard.

✨ Key Features

📝 Task Management
⏱️ Pomodoro Timer
🎯 Daily Goals
📊 Analytics
🔎 Search & Filters
💡 Smart Suggestions

📸 Project Screenshots

These screens show the main parts of the StudyFlow productivity system.

🏠 Dashboard Study overview & productivity stats
⏱️ Focus Timer 25-minute focused study sessions
🎯 Daily Study Goal Set and track daily study targets
📊 Analytics Study statistics & completion rate
🤖 Smart Suggestions Personalized rule-based study suggestions
📝 Task Management Add, search, filter and manage tasks

🛠️ Technologies Used

HTML5 CSS3 JavaScript LocalStorage Responsive Design

🧠 What I Learned

Building StudyFlow helped me practice JavaScript logic, DOM manipulation, local data storage, user interaction, responsive design and creating a complete project from idea to implementation.
